Implement it

Add it to your page

Create one stream on your server, then hand the page its id and public token. The adapter derives the master, signaling and config URLs.

1. Server — create the stream

curl -s https://seedess.com/api/v1/streams \
  -H "Authorization: Bearer key_…" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://origin.example/master.m3u8","id":"demo"}'

2. Page — one player

import { createPlayer } from 'https://seedess.com/p2p.js';

const player = await createPlayer(document.querySelector('video'), {
  stream: 'demo',
  token: 'pk_…',
});

player.on('stats', console.log);

3. Or patch every hls.js player

import { auto } from 'https://seedess.com/p2p.js';

auto({ stream: 'demo', token: 'pk_…' });

const hls = new Hls();
hls.loadSource(masterUrl);
hls.attachMedia(video);

Read the quickstart · API reference · Source on GitHub

Both videos are the same stream and muted for autoplay. Viewer A seeds the segments it has already fetched; Viewer B joins the same signaling room and requests them over WebRTC. When no peer has a segment, the player falls back to the CDN.

One-line rollback: remove the adapter and the player is stock hls.js again.
